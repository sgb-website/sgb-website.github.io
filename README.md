# 🚀 SGB Bot

![Version](https://img.shields.io/badge/Version-3.0-10b981?style=for-the-badge)
![License](https://img.shields.io/badge/License-Proprietary-blue?style=for-the-badge)

**SGB Bot** は、Discord上で本格的なRPG体験やミニゲームを楽しめる多機能ゲームボットです。冒険、バトル、経済システム、ギルド活動など、サーバーメンバーと遊べる多彩な機能を備えています。

---

## 🌟 主な機能

- ⚔️ **冒険・戦闘・エリア移動**
  - エリアを移動しながらモンスターとバトル。戦闘には「攻撃」のほか「防御」コマンドや連打防止システムを搭載。
- 🎰 **カジノ・デイリー報酬**
  - 毎日もらえるデイリー報酬や、獲得したコインで遊べるカジノ機能を実装。
- 🏰 **ギルド機能**
  - プレイヤー同士でギルドを結成・加入し、協力してゲームを進めることが可能。
- 🏦 **銀行利息システム**
  - 預金しておくだけで自動的に利息が増える経済メカニズムを導入。
- 🛠️ **管理者専用機能**
  - サーバー管理者向けの統合管理コマンド（`/admin_sys`）で柔軟な設定・運用が可能。
- 📡 **SGB MONITOR**
  - リアルタイムでの自動アナウンス配信や定期システム告知機能を搭載。

---

## 🎮 コマンド一覧

| コマンド | 説明 | 権限 |
| :--- | :--- | :--- |
| `/play` | ゲームを開始し、メインメニューを表示します | 全ユーザー |
| `/daily` | デイリー報酬を受け取ります | 全ユーザー |
| `/casino` | カジノミニゲームをプレイします | 全ユーザー |
| `/bank` | 銀行への預金・引き出し・残高確認を行います | 全ユーザー |
| `/guild` | ギルドの作成・参加・確認を行います | 全ユーザー |
| `/move` | 別のエリアへ移動します | 全ユーザー |
| `/admin_sys` | ボットのシステム設定・管理を行います | 管理者のみ |
